# Canonical license texts

Before the first public release run:

```bash
./scripts/vendor_licenses.sh
```

This downloads the unmodified SPDX canonical text files for `AGPL-3.0-only` and `CERN-OHL-S-2.0` into this directory. The short root-level files `LICENSE_SOFTWARE` and `LICENSE_HARDWARE` define scope and license choice; these canonical texts provide the complete terms.
