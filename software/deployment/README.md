# Deployment and Benchmarking

This subtree contains one-click deployment, systemd units, shared-memory runtime wiring, TensorRT engine generation and latency auditing.

The `<5 ms` requirement is a target for the compute/transport path after the required neural window is available. Reports must publish measured percentile values rather than converting the target into an unverified claim.
