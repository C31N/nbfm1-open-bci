# NBFM-1 Inference

This subtree contains the NBFM-1 PyTorch model, ONNX export, TensorRT/ONNX Runtime integration and inference daemon. Software here is `AGPL-3.0-only`.

Required architectural properties are causal fast-path processing, asynchronous slow-context cross-attention, Gaussian motor uncertainty, explicit intent probability and time-distributed CTC speech logits.
