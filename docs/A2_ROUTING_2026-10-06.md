# A2 routing investigation — 2026-10-06

Punkt 2 remains open. The primary engineering PCB still has 499 KiCad unconnected items. No routed candidate from these tests has been promoted and fabrication release remains blocked.

## Reproducible pipeline corrections

- FreeRouting 2.4.1 rejects `router.autorouter.max_passes`; use `router.max_passes`.
- Use colon-separated timeouts (`00:15:00`), plus a 960-second subprocess limit. The exact pinned build interprets `90s` as an invalid duration, despite the settings comment suggesting that syntax.
- Disable analytics and profile telemetry explicitly.
- Use `board.GetAreaCount()` for KiCad 8 zone counting; keep the native zone collection passed directly to ZONE_FILLER.
- Save router logs, result JSON, DSN and SES even when a round fails, and checkpoint native DRC metrics after each completed round.
- Disable automatic neckdown and the separate FreeRouting fanout stage. Disabling automatic neckdown alone does not prevent fanout-generated tracks narrower than native KiCad rules. Existing board routing/escapes are retained for each routing round.
- Retain strict-zero native KiCad promotion: no geometric errors, warnings, or unconnected items. Router-internal metrics cannot authorize promotion.
